Can a neural model read the scan better?

I trained a CNN and bidirectional GRU with CTC on 3,000 labeled newspaper lines and compared its output with the archived OCR.

Williamsburg pilot

On ten manually cropped and transcribed lines, character error fell from 24.3% to 5.4%. Word error fell from 58.8% to 25.0%.

The neural model recovered “Clymer” and “Western Railroad”, but still misspelled Williamsburg.

See every line and both OCR outputs

Separate public test set

On 240 lines from ten unseen pages, the model reached 12.4% character error, with 111 lines transcribed exactly. The dataset publisher describes its references as model-verified.

This pilot measures recognition on line images. Full-page layout and changes in search quality still need evaluation. The live search index continues to use archived OCR.
